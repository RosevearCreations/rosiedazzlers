# Project Brain — Build 142

Rosie Dazzlers is moving from a brochure site into an operations app. Keep the customer-facing site simple, local, and crawlable while moving editable business rules into Admin App and Supabase.

Core principles:
- `dev` is the working branch.
- JSON is allowed as a fallback, but DB/app settings should become canonical where business users edit data.
- Every public page should have one clear H1.
- Local town/service wording should be prominent but natural.
- Admin workflows should be mobile-friendly and forgiving.
- Error handling should fall back instead of blanking pages.
