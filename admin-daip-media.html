  3. Leave r2.dev and Custom Domains disabled. This bucket must stay private.

  5. Open Settings → Bindings → Add → R2 bucket.
  6. Variable name: DAIP_MEDIA_BUCKET.
  7. Select rosie-daip-media, save, and configure both Preview and Production if they are separate.
