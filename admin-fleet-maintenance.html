Fleet maintenance operating help

  1. Use the saved vehicle UUID as the planning authority; never guess which vehicle a completed booking belongs to.
  2. Set an interval from 14–84 days when the vehicle has a predictable maintenance rhythm.
  3. Use a next cleaning date for a manual follow-up target. A past date is allowed so overdue vehicles can remain visible.
  4. Use next service mileage only when the customer vehicle has a meaningful current mileage; the target cannot be below the stored current mileage.
  5. No automatic scheduling: saving a plan does not reserve a date or time.
  6. No recurring billing: saving a plan does not authorize a charge, membership, or subscription.
  7. If a history appears in “needs review,” resolve vehicle identity through normal customer/staff records before using it for reminders.
