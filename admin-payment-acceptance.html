Operating Help

What does configuration ready / evidence pending mean?

Development has a Stripe test key, but the persisted final-balance records do not yet contain Stripe checkout or paid evidence. Configuration readiness is not transaction acceptance.

What is checkout evidence?

The application persisted a Stripe checkout session reference and checkout-created timestamp. It proves the existing checkout workflow reached session creation; it does not prove payment completed.

What is persisted paid evidence?

A Stripe payment request is stored with a paid timestamp and a paid/succeeded state. Build 319 reports that application evidence conservatively. It does not claim an independently verified webhook because current source evidence does not establish that assurance.

Why does a live Stripe key block Development?

Development payment acceptance must use test credentials. If a live secret is detected, provider acceptance is blocked until the server-side environment is corrected.

Why is PayPal not accepted?

PayPal is not integrated in the current source, so there is no legitimate PayPal sandbox acceptance evidence to report.

Does manual payment count as Stripe acceptance?

No. Manual handling remains an operational fallback and can have its own persisted paid record, but it is deliberately excluded from Stripe provider acceptance.
