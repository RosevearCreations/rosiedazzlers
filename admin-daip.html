What this build can and cannot do

Enabled

  • Create a private internal-test DAIP job tied only to an opaque DAIP test reference.
  • Register harmless file metadata only—no file transfer.
  • Record internal privacy review and immutable audit events.
  • Archive a test job without deleting its audit trail.

Deliberately disabled

  • No original upload, R2 bucket, signed URL, Google Drive sync, or file download.
  • No proxy worker, FFmpeg, AI, transcription, computer vision, export, gallery reuse, customer view, or publishing.
  • No customer media, incident evidence, addresses, VINs, payment material, or personal details.
Loading safeguards…

1. Create an internal test job

Use a DAIP-only test reference, never a booking UUID. The Test Lab does not connect to or display customer names, addresses, vehicle details, or media.

2. Register harmless test asset metadata

This does not upload a file. Do not paste URLs, storage keys, paths, signed links, or Drive references.

3. Record internal privacy review

A cleared result means only “safe for internal test review.” It never becomes public consent or public approval.
