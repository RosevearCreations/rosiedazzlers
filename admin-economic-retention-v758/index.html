ⓘ Help / configuration

Which provider settings are needed?

On the server only: ROSIE_ECONOMIC_RETENTION_VERIFY_BASE_URL (a trusted HTTPS origin), ROSIE_ECONOMIC_RETENTION_PROVIDER_PUBLIC_KEY_B64 and ROSIE_ECONOMIC_RETENTION_PROVIDER_KEY_ID. The signing key must be independent from the owner, source witness and history custodian. A configured URL must not come from submitted customer data.

What is owner migration authorization?

This build verifies a signed request for independent DBA/security review, binding the exact plan hash, source history and independent retention receipt. Actual migration execution still needs separate explicit permission and an audited deployment workflow.

Will this affect live prices or bookings?

No. This review is private and read-only. Basic Detail starting prices ($229/$269/$309 CAD), other services, consumables, travel, payroll, customer communications, payments, and winter restrictions are unchanged.
