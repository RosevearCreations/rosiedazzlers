Payment Reconciliation

Read-only comparison of the persisted final-balance request, the booking final-payment ledger, and the exact Stripe Checkout Session. This resolves whether a payment mismatch needs operator attention without creating a new charge or finance entry.

Fail-closed reconciliation contract
  • No charge, checkout creation, finance write, customer notification or recurring billing.
  • Stripe is queried by GET only when the environment policy allows it.
  • Amount, currency and request identity must match before provider-paid evidence is considered actionable.
  • Webhook verification is not asserted.
  • The current booking-finance writer has no database-enforced provider idempotency key, so Build 321 does not auto-post final-payment entries.

Operating Help

What does reconciliation required mean?

Stripe reports the exact Checkout Session paid and the session amount, currency and request identity match Rosie Dazzlers, but the local tracked request or booking final-payment ledger does not yet agree.

Why doesn’t this screen post the payment automatically?

The existing booking-finance writer appends events but does not have a database-enforced unique provider reference. Automatically posting here could create duplicate finance entries if two reconciliation actions raced or an operator repeated the action. Build 321 therefore reports the evidence and directs the operator to the existing Booking Workbench finance workflow.

What is an identity mismatch?

The provider amount, currency, request reference or booking metadata does not agree with the local payment request. Treat that as a blocker; do not make a finance correction from provider state alone.

Does “Stripe paid” mean webhook verified?

No. This screen queries the exact Checkout Session directly using a read-only GET. It does not claim that a webhook independently delivered or verified the payment.

What if the session is expired?

An unpaid expired checkout belongs in Payment Recovery, where the existing session is checked before any replacement is considered.
