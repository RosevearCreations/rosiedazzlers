- Production is proposed by PR from accepted Development to protected `main`; protection is not bypassed.

- Database/schema changes are separate explicit acceptance boundaries and are applied Development-first before dependent Production code.

- Public SEO retains exactly one meaningful H1 per indexable page, unique metadata/canonical/structured data and truthful local/service proof.
- Phone/tablet/desktop behavior remains a continuing acceptance dimension; source checks are not mislabeled as visual browser proof.
