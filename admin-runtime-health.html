Important distinction

How to use this during testing

  1. Leave the recorder enabled while doing normal admin testing.
  2. When a button reports a failure, open this page and export the JSON before clearing anything.
  3. In Cloudflare Observability, compare the route and Ray ID with invocation CPU/outcome when Workers Logs are available.
  4. Do not repeatedly retry an operation that returned 5xx until its state is checked; CPU termination can occur after a write has already succeeded.
