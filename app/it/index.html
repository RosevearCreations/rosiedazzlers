Readiness & release gate

One explicit check verifies runtime branch/SHA identity, authentication, a minimal Supabase read, public R2, private DAIP R2 and payment-provider configuration. It classifies problems as deployment, database, configuration or provider issues and supplies a corrective action without exposing secret values.

Release policy

What this control can and cannot do

Runtime identity Cloudflare branch and commit SHA are displayed when the runtime provides them.
CI authority GitHub exact-SHA checks remain authoritative. This runtime never needs or exposes a GitHub token.
Production business-data mutation Closed from the readiness endpoint. Promotion, schema changes, R2 writes, provider writes and business-data mutation require their owning deliberate workflows.
Secrets Only presence/mode indicators are returned. Secret values are never returned to the browser.
