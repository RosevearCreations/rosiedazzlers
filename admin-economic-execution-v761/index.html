ⓘ Help and safety

What additional server settings are needed?

The operator origin ROSIE_ECONOMIC_TRIAL_OPERATOR_BASE_URL and distinct signer ROSIE_ECONOMIC_TRIAL_OPERATOR_PUBLIC_KEY_B64 / ROSIE_ECONOMIC_TRIAL_OPERATOR_KEY_ID; and separate post-trial witness origin ROSIE_ECONOMIC_TRIAL_RECONCILE_BASE_URL with ROSIE_ECONOMIC_TRIAL_RECONCILER_PUBLIC_KEY_B64 / ROSIE_ECONOMIC_TRIAL_RECONCILER_KEY_ID. All nine previous independently pinned keys and project settings remain required.

Can this page run the migration?

No. Execution is a distinct, separately approved nonproduction operator workflow outside this site. These reports only reconcile claimed execution against original script hashes, target project, approval times and independent results.

What if a rollback occurred or evidence disagrees?

The case stays HOLD; preserve the original operator and witness records, inspect exact rollback artifacts with the DBA/security reviewers, and require a new explicit owner disposition. No automatic retry, closure or production migration.
