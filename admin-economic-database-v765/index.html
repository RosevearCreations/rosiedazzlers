ⓘ Help and limits

What must the database inspector check?

Using an external read-only connection to the exact production project, independently compare the deployed schema fingerprint, migration version and history, database identity and a hashed inspection transcript to the historical signed operator claim.

What counts as immutable audit enforcement evidence?

A separately signed external inspection must reference table definition, append-only insert and rejected UPDATE/DELETE probes, privileged roles, RLS, retention policy and log-chain hashes. Separate controlled proof of storage enforcement and access remains the responsibility of the external auditor.

Can this ready state authorize closing a case?

No. Even with all authentic claims and the owner acknowledgement, this screen only creates an unsigned handoff for a new independent owner closure authorization and append-only recorded decision. A migration, rollback or notification is never run here.
