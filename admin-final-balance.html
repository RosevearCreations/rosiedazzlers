Operating Help

Ready

A positive service balance remains, the job is in progress or completed, and there is no active final-balance request. Review the calculation, then use Create request only when you intend to open a tracked payment request.

Blocked

The cockpit found a condition that should be resolved first, such as a missing/zero booking total, a job that has not reached the payment handoff stage, an unavailable finance read, or an expired/cancelled request requiring review.

Requested

A tracked final-balance request is already open or sent. Do not create a duplicate. Open the request handoff details and deliberately create a hosted checkout only when required.

Paid / Closed

The local finance ledger calculates no remaining service balance, or the tracked payment request reports paid. No new request should be created without first reconciling the booking.

How the amount is calculated

Calculated due uses the booking total minus recorded deposits, final payments, discounts and other service collections, plus recorded refunds. Tips are intentionally excluded from the service-balance calculation.
