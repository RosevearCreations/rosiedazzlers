ⓘ Help and safety

Does a signed operator completion mean the case is closed?

No. A signature is a claim from an external witness. Independently review the original records, change-manager authorization, operator report and database state before making a separate owner acceptance decision.

What happens if evidence is missing or contradictory?

The result remains HOLD. Keep original incident evidence and do not retry an uncertain operation, forge a missing receipt or manually override the result in the browser.

Can this page connect to the production database?

No. It only checks externally signed evidence from server-approved HTTPS origins. It cannot run SQL, trigger a closure, change a ledger or send a customer message.
