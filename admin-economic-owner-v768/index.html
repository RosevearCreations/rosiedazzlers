ⓘ Help and safeguards

What do the three owner decisions mean?

The original owner may sign manual evidence-review readiness, a request for separate external exception reopening, or HOLD. None authorizes this website to change a production record. An externally signed reopening claim must be manually confirmed against the original case register.

How is original-source custody checked?

The independent custodian must bind the exact original operator, post-change inspector, DBA and audit receipt hashes, including previous/new custody and retention digests. A signed report is still only the custodian's claim; original storage must be audited outside the app.

What if there is a conflict or critical exception?

Retain HOLD, preserve the original source records and reconcile with the independent reviewer. Do not retry an uncertain closure, delete the case, or bypass the signed evidence chain.
