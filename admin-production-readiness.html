Operating Help

What does “ready for human review” mean?

It means the evidence visible to this runtime has no explicit blocker. It does not mean Production has been approved, promoted, or changed.

Why can runtime identity be incomplete?

Cloudflare Pages build metadata is not guaranteed to be exposed to Functions as runtime bindings. When branch, SHA or deployment URL cannot be proven, this dashboard reports the evidence as unavailable instead of inferring it.

Where are the live CI results?

The source gate, Development acceptance and rollback/recovery workflows remain the canonical exact-SHA release evidence in GitHub. This page confirms those authorities exist in source but does not invent their current run status.

What blocks a Development release review?

A Production-like runtime, a live Stripe credential on Development, or an unclassifiable Stripe credential is treated as a blocker. Missing metadata or an unconfigured test provider remains incomplete evidence.

Can this page roll back or promote?

No. Rollback readiness and stuck-deployment recovery are separate guarded workflows. Production promotion remains closed until explicitly authorized.
