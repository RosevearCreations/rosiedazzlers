Where values belong

1. Obtain it at the provider

Create the Pixel, Tag, measurement ID, business connection, or OAuth credential in the provider’s official business console.

2. Add it in Cloudflare

Cloudflare Dashboard → Workers & Pages → your Rosie Dazzlers project → Settings → Variables and Secrets → Add → Secret.

3. Check readiness here

This screen reports only configured/missing and format validity. It cannot show the actual value.

4. Test before production

Use staging/test mode, grant marketing consent on a public test page, then verify provider test tools before enabling production mode.

Do not paste any key into Admin Site Settings, Social Queue notes, a Markdown file, GitHub, browser code, or Supabase. Enter every connection value as a Cloudflare encrypted secret. Pixel/tag IDs become visible in the public page only after a visitor permits optional measurement; OAuth tokens and access tokens never leave the server.

Safe test order

  1. Set MARKETING_TRACKING_MODE=test and add only one provider’s ID/credential group.
  2. Deploy to the staging Pages project, open a normal public marketing page in a private window, and choose optional measurement.
  3. Use that provider’s official test/diagnostic tool. Do not use a real customer booking, payment, VIN, address, quote, progress link, or uploaded media.
  4. Record only a pass/fail note in the Guided Production Test Centre. Never paste IDs, tokens, screenshots containing values, or URLs with customer information.
  5. Keep production mode off until the privacy notice, consent behavior, and test evidence are accepted.
