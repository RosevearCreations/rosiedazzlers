# Standard Jobs and Creative Project Opt-In — Build 229

## Rule
A customer booking is a standard job unless staff deliberately promotes it into a creative project.

## Standard job
Uses the existing booking, assignment, live update, proof, invoice, payment, review and completion workflow. It carries no project-output checklist and requires no content-production work.

## Creative project opt-in
Creates a separate project linked to the booking. The booking remains the operational source of truth; the project owns documentary sessions, lessons, costs and governed output plans.

## Safety
No automatic conversion, no duplicate project per booking, no automatic publication, and no bypass of consent or DAIP gates.
