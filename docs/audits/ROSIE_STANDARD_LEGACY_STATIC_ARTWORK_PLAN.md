## Authority and rules

- The single numbered authority remains `data/application_static_image_catalog.json`
  and its generated `docs/audits/ROSIE_APPLICATION_STATIC_IMAGE_CATALOG.md`.
- IMG-001–062 are reserved Standard theme images; the remaining IMG-063–116
  are 54 shared application/Admin assets, **not 54 customer photographs**.
- New owner-approved image variants belong in
  `assets/themes/standard/images/` (Admin vectors under
  `assets/themes/standard/admin/`). Never overwrite original shared runtime
  JPG/PNG/SVG files by filename alone.
- The static source path does not establish that a page uses that image.
  Verify actual rendered placement, CSS cropping, accessible labels and R2/
  Photo Studio precedence before wiring a new theme asset.
- No generated scene is authentic customer proof, an actual inventory count,
  a verified customer testimonial, or documentary photography of a town.
