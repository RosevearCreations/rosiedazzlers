What extra evidence is required?

Server settings: ROSIE_ECONOMIC_ROLLBACK_EXCEPTION_BASE_URL and its separately pinned ROSIE_ECONOMIC_ROLLBACK_EXCEPTION_PUBLIC_KEY_B64 / ROSIE_ECONOMIC_ROLLBACK_EXCEPTION_KEY_ID, plus ROSIE_ECONOMIC_CHANGE_CONTROL_BASE_URL and separate ROSIE_ECONOMIC_CHANGE_CONTROL_PUBLIC_KEY_B64 / ROSIE_ECONOMIC_CHANGE_CONTROL_KEY_ID. All eleven earlier signers remain mandatory. The owner signs the new decision with the existing pinned owner key using a different signing domain.

What does “ready for separate authorization” mean?

The external trial claims, rollback disposition, owner acceptance and independent change design agree on one isolated project and exact artifact hashes. Production migration still needs an explicit future DBA, security and owner change approval, a separately authorized operator and execution evidence.

What happens if a rollback was reported?

The independent reviewer can attest that the rollback exception remains held. Owner sign-off records HOLD, never closes the incident. Follow a separately approved investigation and recovery process. There is no automatic replay, migration, storage change or customer notification here.
